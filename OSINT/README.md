# OSINT

L’OSINT, ou renseignement en sources ouvertes, consiste à rechercher, recouper et vérifier des informations accessibles publiquement. Une information publique n’est pas automatiquement libre de tout usage : la vie privée, les conditions des services et la législation restent applicables.

## Ce que couvre cette catégorie

Le fichier [site.md](site.md) rassemble des outils web et locaux pour :

- rechercher un pseudonyme sur plusieurs plateformes ;
- analyser des métadonnées d’image ;
- vérifier des informations publiques liées à un domaine ou une adresse IP ;
- organiser une recherche avec OSINT Framework ;
- étudier des vulnérabilités publiées dans un objectif défensif.

La note détaille aussi l’installation de h8mail, Toutatis, Sherlock, DaProfiler, GitFive et IPinfo CLI.

## Méthode recommandée

Commencez par une question précise et un périmètre autorisé. Notez la source, la date et le niveau de confiance. Recoupez les informations avec plusieurs sources indépendantes et ne publiez que les données nécessaires.

Les outils locaux doivent être utilisés sur vos propres comptes, vos domaines de test ou des données pour lesquelles vous avez une autorisation explicite. Consultez la liste complète et les commandes : [site.md](site.md).
