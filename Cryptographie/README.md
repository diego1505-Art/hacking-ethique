# Cryptographie

La cryptographie regroupe les techniques qui protègent ou transforment l’information. Elle comprend notamment le chiffrement, le déchiffrement, le hachage, les signatures et l’encodage.

Il faut distinguer trois notions :

- **Encodage :** représentation différente d’une donnée, réversible sans secret particulier, comme Base64.
- **Chiffrement :** transformation protégée par une clé, conçue pour empêcher la lecture sans autorisation.
- **Hachage :** empreinte généralement non réversible, utilisée notamment pour vérifier l’intégrité ou stocker des mots de passe de manière adaptée.
